# battleship-rs

A battleship game written in Rust.

## what?

This repo will contain the code for running battleship and playing battleship either through a CLI or the web.

## why?

For fun and to learn a few things:

- General Rust code
- Wasm in Rust
- Use React with Wasm + Rust
- CLI in Rust
- Structuring of Rust projects
- Practice OOP in Rust
- Unit testing in Rust
- Hosting Wasm apps in the cloud
- Custom user auth
- Some distributed system fun

## roadmap

1. A basic implementation of battleship that can be played in the CLI. :white_check_mark:
2. A basic implementation of battleship that can be played on the web.
3. Add React + Typescript + Vite on the web.
4. Add local multiplayer to CLI: local stat saves. (optional)
5. Create player profile web application: user auth, account management. (optional)
6. Add multiplayer functions to web app: user auth, lobbies, invites, stat saves. (optional)
7. Add online functions to CLI: user auth, offline mode, local stat saves. (optional)
